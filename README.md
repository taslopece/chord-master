# Chord Master

一组纯前端、可离线打开的和弦学习与听感训练工具。

## 工具

- `index.html`：产品主页与工具入口
- `chord-atlas.html`：和弦图鉴，查看理论、指板并试听和弦
- `ear-training.html`：听辨训练，通过真实吉他采样判断常用和弦类型

在和弦图鉴中，可以通过点选调性、调式、和弦根音、和弦类型和斜杠低音，查看：

- 相对根音的和弦公式
- 相对当前调性的简谱构成音
- 实际音名
- 吉他标准调弦与四弦贝斯指板上的构成音位置

## 使用

下载或克隆本仓库后，直接用浏览器打开任意 HTML 页面即可。项目不依赖网络、构建工具或第三方安装包。

黄色表示根音；青色表示其他和弦构成音。

## 当前支持

- 12 个常用调性
- 大调与自然小调
- 三和弦、七和弦与常用扩展和弦
- 斜杠和弦低音
- 0–12 品吉他及四弦贝斯指板
- 吉他齐奏、扫弦与琶音试听
- 贝斯根音与琶音试听
- 大三、小三、属七、大七和小七和弦听辨训练
