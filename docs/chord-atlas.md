# 和弦图鉴功能设计

## 功能定位

和弦图鉴是一个主动查阅和理解和弦的工具。用户已经知道自己想查看什么，通过选择调性、根音和和弦类型，获得视觉与听觉上的解释。

它不是测试页面，不隐藏答案，也不记录答题成绩。

## 独立入口

- 规划页面：`chord-atlas.html`
- 可以从产品主页进入。
- 可以通过独立 URL 直接打开、收藏和分享。

在多页面重构完成前，现有功能暂时仍位于 `index.html`。

## 当前能力

- 选择当前调性和大调／自然小调。
- 选择和弦根音与和弦类型。
- 选择低音，显示斜杠和弦。
- 展示和弦公式、调内简谱、实际音名和学习提示。
- 展示吉他与四弦贝斯的 0–12 品指板。
- 使用颜色区分根音和其他构成音。
- 使用明显的上弦枕区分空弦与 1 品。
- 吉他试听：齐奏、向下扫弦、琶音。
- 贝斯试听：根音、琶音。

## 页面结构

1. 页面标题与工具导航。
2. 和弦选择控制区。
3. 和弦名称与理论解释区。
4. 吉他和贝斯听感区。
5. 吉他和贝斯指板区。

所有区域共同反映当前所选和弦。根音、和弦类型或低音变化时，旧音频应立即停止，避免视觉信息和声音不一致。

## 音频规则

### 吉他

- 齐奏：所有配置音同时开始，便于识别整体色彩。
- 扫弦：从低音到高音依次触发，模拟向下扫弦。
- 琶音：以更明显的间隔依次播放，使用户听清内部音程。

现阶段由程序生成合理的开放排列，不代表真实的固定吉他指法。

### 贝斯

- 根音：默认播放和弦根音；选择转位低音后播放所选低音。
- 琶音：从当前低音开始，依次播放和弦构成音。

## 下一阶段

近期优化：

- 播放速度控制。
- 循环播放。
- 琶音播放时同步高亮当前构成音。
- 改善播放中的加载、错误和激活状态。

后续能力：

- 吉他和弦指法图。
- 开放式、封闭式及不同把位选择。
- 标记不弹弦、空弦和按弦位置。
- 严格按照当前指法播放齐奏、扫弦和琶音。

## 与其他工具的边界

- 图鉴负责解释用户主动选择的和弦。
- 听辨训练负责隐藏答案、随机出题、判分和统计。
- 两者共享理论与音频引擎，但不共享页面状态。
