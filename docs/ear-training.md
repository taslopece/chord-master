# 听辨训练功能设计

## 功能定位

听辨训练是一个从声音出发识别和弦的测试工具。核心闭环为：

```text
设置训练范围 → 播放题目 → 用户作答 → 判定结果 → 查看解析 → 下一题
```

它与和弦图鉴的区别是默认隐藏和弦名称、构成音和指板答案，要求用户先通过听觉判断。

## 独立入口

- 规划页面：`ear-training.html`
- 可以从产品主页进入。
- 可以通过独立 URL 直接打开、收藏和分享。

## 第一版训练范围

第一版只训练五种常用和弦性质：

- 大三和弦
- 小三和弦
- 属七和弦
- 大七和弦
- 小七和弦

训练设置允许用户选择参与出题的类型。初学者可以只比较大三与小三，熟悉后再逐步加入七和弦。

## 第一版交互流程

1. 用户选择训练范围与播放方式。
2. 系统从允许的根音和和弦类型中随机生成题目。
3. 用户点击播放或重播。
4. 用户选择听到的和弦类型。
5. 提交后立即显示正确或错误。
6. 展示和弦名称、公式、构成音及简短听感提示。
7. 用户进入下一题。

提交答案前不得显示能直接泄露答案的信息。

## 播放方式

第一版复用和弦图鉴的音频引擎：

- 吉他齐奏
- 吉他扫弦
- 吉他琶音

后续可以加入贝斯辅助播放，但默认训练声音应保持一致，避免用户通过不同音色猜测答案。

## 反馈与统计

第一版显示：

- 当前题号
- 本轮答对数量
- 本轮正确率
- 当前连续答对次数

统计首先保存在当前页面会话中。后续再决定是否使用 `localStorage` 保存历史成绩和错题，不需要后端账户系统。

## 难度演进

### 基础

- 只判断和弦性质。
- 根音固定或在小范围内变化。
- 可以重复播放。

### 进阶

- 同时判断根音与和弦性质。
- 加入转位。
- 限制重播次数。
- 扩展到减三、增三、挂留与扩展和弦。

### 高阶

- 连续和弦进行听辨。
- 调内级数判断。
- 限时训练。
- 针对错题自动增加相似和弦对比。

## 结果解析

结果页不是简单显示答案，而应解释：

- 正确和弦名称与公式。
- 实际构成音。
- 最有辨识度的音程，例如大／小三度、大小七度。
- 与用户所选错误答案之间的关键差异。
- 跳转到对应和弦图鉴的入口。

## 与和弦图鉴的边界

- 听辨训练不承担完整的自由查阅功能。
- 答案揭晓后可以复用图鉴的数据展示组件，但应保持训练流程的完整性。
- 跳转到图鉴时，通过 URL 参数传递根音和和弦类型，图鉴仍可独立打开。

## 实现顺序

1. 建立独立页面和基础布局。
2. 抽取并复用理论与音频模块。
3. 实现训练范围设置与随机出题。
4. 实现播放、答案选择和判定。
5. 实现本轮统计与答案解析。
6. 增加速度、循环、高亮与难度设置。
